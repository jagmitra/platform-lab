Policies

Guardrails Kyverno enforces on every cluster in the fleet.

Active policies

PolicyWhat it checksModeScope
require-requests-limits Every container sets CPU and memory requests and a memory limit - App namespaces; system namespaces excluded

How a request is checked

  • RBAC decides whether you may create the resource in that namespace
  • Kyverno’s admission webhook checks the resource against the policy
  • Audit allows it and records a PolicyReport; Deny rejects it
  • The reports controller also scans existing resources in the background

Test it yourself

kubectl -n intern-sandbox apply -f tests/policies/bad-pod.yaml --as=intern
kubectl get policyreport -A
